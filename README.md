# BOSS 直聘 自动投递助手

按「Agent·智能体·大模型·AI应用 / 广州 / 4K 起 / 应届或实习 / 本科」批量打招呼，工作日上午 10:00、下午 14:00 各跑一轮。

## 为什么是浏览器扩展，而不是脚本控制浏览器

实践验证：用 Playwright / CDP 接管 Chrome 访问 BOSS直聘，登录页会在 1.5 秒内被强制跳回首页，职位页会被重定向到 `?_security_check=1` 的风控页。也就是说 BOSS 能识别 CDP 自动化。
因此改用 **Chrome 扩展**：脚本跑在正常浏览器页面里（`navigator.webdriver` 为 false，无 CDP 连接），行为与真人点击一致，风控风险低得多。

## 一次性安装（约 2 分钟）

1. Chrome 打开 `chrome://extensions/`
2. 右上角打开 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择：
   `C:\Users\EDY\Documents\deepseek-harness\default-workspace\boss-auto\extension`
4. 打开 <https://www.zhipin.com> 并用 BOSS APP 扫码登录（登录态会保存在你自己的 Chrome 里）
5. 点扩展图标 → 打开设置页，确认条件：
   - 岗位关键词：`AI应用开发`
   - 城市：`广州`
   - 薪资：`4` — `10` K，匹配方式 **只卡下限**（岗位薪资上限 ≥ 4K 即通过，不封顶；日薪按时薪折算月薪）
   - 经验要求：`应届,经验不限,1年以内,实习,在校`（实习岗位自动放行）
   - 学历要求：`本科,硕士,学历不限`
   - 每日上限：`20`
   - 打招呼语：留空（= 发送 BOSS 默认话术）
   - **演练模式：先保持勾选**
6. 设置页点 **保存设置** → **打开投递页**

## 使用

- **演练**：右下角面板显示「演练中」，逐个打开岗位、点「立即沟通」前停下，只记录命中情况，不发消息。面板「导出」可看 CSV。
- **正式**：设置页取消勾选「演练模式」→ 保存。之后打开带 `bossauto=1` 的链接即自动跑。
- 投递页链接（设置页会显示）：
  `https://www.zhipin.com/web/geek/jobs?query=AI应用开发&city=101280100&bossauto=1`
- 面板可以随时「停止」；点「开始」可在非时段手动跑一轮。

## 安全设计

| 机制 | 说明 |
| --- | --- |
| 时间窗口 | 仅周一至周五 10:00–11:30、14:00–16:00 内自动启动 |
| 每日上限 | 默认 20，当日累计到上限即停 |
| 薪资匹配 | `只卡下限`：岗位薪资上限 ≥ 期望下限即通过；`区间交集`：需与期望区间重叠 |
| 随机间隔 | 每个岗位之间 25–75 秒随机等待 |
| 去重 | 已打过招呼的岗位 ID 记 60 天，不会重复骚扰 |
| 风控熔断 | 检测到验证码 / `_security_check` 立即停止并提示人工处理 |
| 演练模式 | 默认开启，先看命中率再决定是否真发 |

## 风险提示

- 自动投递/批量打招呼**违反 BOSS直聘 用户协议**，平台有权限制账号功能甚至封号；请自行评估。
- 建议从小量开始（例如每日 10 个），观察几天账号状态再放大。
- 投递过去的岗位 HR 会看到你的打招呼记录，话术与筛选条件建议贴近真实求职意向。

## 踩过的坑：BOSS 的薪资数字是「私有区字符」混淆

DOM 里看到的薪资不是 `260-300元/天`，而是一串私有区码位：

```
<span class="job-salary">\uE033\uE037\uE031-\uE034\uE031\uE031元/天</span>
```

对应关系固定为 `U+E031→0 … U+E03A→9`。不还原的话 `innerText` 出来是 ` - 元/天`，薪资恒为空，所有岗位都会被薪资过滤掉。扩展里的 `decodePua()` 负责还原；`tests/filter_regression.js` 可以用真实导出的诊断 JSON 回归验证。

## 整体架构（三个可独立运行的部分）

```
┌─────────────────┐   POST /ingest   ┌──────────────────────────────┐
│ extension/      │ ────────────────►│ jobpilot/   (后端大脑)        │
│ BOSS 页面操作   │                  │  Redis 去重 + 配额             │
│ v2.6            │                  │  Qdrant JD 相似度去重          │
└─────────────────┘                  │  LangGraph 打分 → 决策         │
                                     │  MySQL/SQLite 落库            │
┌─────────────────┐   /jobs  /stats  │  React 看板 + WS 实时          │
│ jobgraph/       │ ◄────────────────┤  MCP Server（给 Agent 调用）   │
│ LangGraph 决策  │                  └──────────────────────────────┘
└─────────────────┘
```

| 目录 | 作用 | 怎么跑 |
| --- | --- | --- |
| `extension/` | 浏览器侧：搜岗位、筛选、点立即沟通、发话术 | 加载到 Chrome，见下文安装 |
| `jobgraph/` | 决策流程原型（标准库 + LangGraph） | `python -m jobgraph.cli` |
| `agentchat/` | 流式 Agent 对话服务（FastAPI/WS/Redis/Qdrant/React） | `uvicorn backend.app:app` |
| `jobpilot/` | 投递链路后端：去重、打分、入库、看板、MCP | `docker compose up -d` 或 `python -m pipeline.api` |
