# 迁移到另一台电脑

目标：在新电脑上还原出一模一样的可用环境——后端能跑、扩展能投、数据和配置都在。

预计 15 分钟。下面按顺序做，每步都有验收点。

---

## 0. 新电脑需要先装的软件

| 软件 | 版本要求 | 用途 |
| --- | --- | --- |
| **Python** | 3.10+（当前用 3.12） | 跑后端与 Agent |
| **Chrome** | 任意较新版本 | 加载扩展、打开 BOSS |
| **Git** | 任意 | 拉代码（也可用 ZIP，见文末） |

验证：

```bash
python --version
git --version
```

---

## 1. 拉代码

```bash
cd C:\Users\<你的用户名>\Documents
git clone https://github.com/terrybertearmnap1-maker/boss-auto.git
```

> 如果 GitHub 连不上（国内常见），git 走代理：
> ```bash
> git config --global http.https://github.com.proxy http://127.0.0.1:7897
> ```

**验收**：`boss-auto\jobpilot\agents` 目录存在。

---

## 2. 装 Python 依赖

```bash
cd boss-auto\jobpilot
python -m pip install -r requirements.txt
```

**验收**：

```bash
python -c "import fastapi, langgraph, httpx; print('ok')"
```

---

## 3. 重建 `.env`（不在仓库里，必须手写）

新建 `boss-auto\jobpilot\.env`：

```ini
OPENAI_BASE_URL=https://api.deepseek.com
OPENAI_API_KEY=sk-你的key
OPENAI_MODEL=deepseek-chat
```

> 没填 key 也能跑，话术会退化成模板（每岗位仍按 JD 技术栈拼，但不会逐条改写）。

**验收**：

```bash
python -c "from pipeline.envload import llm_ready; print(llm_ready())"
```

---

## 4. 迁移「不在仓库里」的私密数据

这些被 `.gitignore` 排除（简历、数据库、解析结果）。**不用一件件拷**，用内置命令打包：

### 旧电脑：导出

```bash
cd boss-auto\jobpilot
python -m pipeline.backup export D:\boss-auto-local
```

输出示例：

```
已导出 17 个文件 → D:\boss-auto-local
  · 简历成品: 13 个文件
  · 简历脚本: 2 个文件
  · 投递数据库: 1 个文件
  · 简历解析结果: 1 个文件
```

### 把导出目录送走，三选一

| 方式 | 怎么做 | 适合 |
| --- | --- | --- |
| **私有 git 仓库**（推荐） | 在 `D:\boss-auto-local` 里 `git init` → push 到私有仓库 | 有版本、可回溯 |
| **网盘同步** | 直接导出到 OneDrive / iCloud 目录 | 最省事，自动同步 |
| U 盘 / 微信文件传输 | 拷一个文件夹 | 一次性 |

### 新电脑：导入

```bash
cd boss-auto\jobpilot
python -m pipeline.backup import D:\boss-auto-local
```

覆盖前的旧文件会自动改名成 `*.bak-时间戳`，不会直接丢。

### 查看当前状态

```bash
python -m pipeline.backup status
```

```
 ✅ 简历成品       2543 KB    C:\Users\EDY\Documents\boss-auto\resume
 ✅ 简历脚本       8 KB       ...\boss-auto\private
 ✅ 投递数据库      48 KB      ...\boss-auto\_local\jobpilot.db
 ✅ 简历解析结果     5 KB      ...\boss-auto\_local\current_resume.json
```

**完全不带这些也能跑**，只是：数据库为空、要重新上传简历、没有简历成品文件。

## 5. 启动后端

```bash
cd boss-auto\jobpilot
python -m uvicorn pipeline.api:app --host 127.0.0.1 --port 8030
```

**验收**：浏览器打开 <http://127.0.0.1:8030>

页面顶部应显示 `db: sqlite · cache: memory · vectors: qdrant · threshold: 60`，
如果迁移了数据库，表格里能看到之前投过的岗位。

---

## 6. 加载浏览器扩展

1. Chrome 打开 `chrome://extensions`
2. 右上角打开 **开发者模式**
3. 点 **加载已解压的扩展程序** → 选 `boss-auto\extension`
4. 确认版本号是最新的（面板右下角显示 `v3.x`）

---

## 7. 重填扩展设置（**最容易漏，但必须做**）

扩展配置存在 Chrome 里，不跟仓库走。点扩展图标 → 设置页，逐项填。

### 筛选条件

| 字段 | 建议值 |
| --- | --- |
| 岗位关键词 | `Agent,大模型,AI应用,智能体` |
| 排除关键词 | `java,后端,服务端,产品经理,销售,客服,运营,标注,训练师` |
| 城市 | `广州,深圳` |
| 期望薪资 | `4` — `10` |
| 薪资匹配方式 | 只卡下限 |
| 经验要求 | `应届,经验不限,1年以内` |
| 学历要求 | `本科,硕士,学历不限` |

### 简历与匹配

| 字段 | 值 |
| --- | --- |
| 核心技能 | `Python,Agent\|智能体,LLM\|大模型,RAG\|检索增强\|知识库,LangChain\|LangGraph,Prompt\|提示词` |
| 加分技能 | `FastAPI,Docker,SQL,向量数据库\|向量检索,工具调用\|Function Calling,MCP,微调\|Fine-tune,多模态` |
| **匹配结果上报地址** | `http://127.0.0.1:8030` |
| 最低匹配分 | `60` |

### 打招呼语

两种写法，任选：

**（A）占位符版**（扩展本地发，不依赖后端）

```
您好，我是27届本科应届生，投递「{岗位}」（{公司}）。看到要求里的{技能}我都有实际项目经验，方便聊聊吗？
```

**（B）后端 LLM 版**（每个岗位单独生成）

设置页勾选 **「自动执行后端下发的投递指令」**，话术由后端生成，
扩展只负责执行。这样 BOSS 上每条话术都不一样。

### 频率与安全

| 字段 | 建议值 |
| --- | --- |
| 每日上限 | `20` |
| 单轮上限 | `2`（首次）/ `8`（稳定后） |
| 投递时段 | `10:00-11:30` / `14:00-16:00` |
| 操作间隔 | `25` — `75` 秒 |
| 演练模式 | 先勾上跑一轮，确认无误再取消 |
| 总开关 | ✅ |

## 9. 重建定时任务

定时任务不在仓库里，新电脑要重建。两种方式：

### 方式 A：Windows 任务计划程序（不依赖任何常驻程序，推荐）

计划程序 → 创建基本任务 → 每天 10:00 / 14:00 → 启动程序：

```
程序：C:\Program Files\Google\Chrome\Application\chrome.exe
参数：https://www.zhipin.com/web/geek/jobs?bossauto=1
```

### 方式 B：让后端跑全流程（需要后端常驻）

定时调用：

```bash
curl -X POST http://127.0.0.1:8030/run -H "Content-Type: application/json" -d "{\"execute\":true}"
```

## 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `python` 不是命令 | 没加 PATH | 用 `py -3` 或重装时勾选 Add to PATH |
| `ModuleNotFoundError: langgraph` | 依赖没装 | 重跑 `pip install -r requirements.txt` |
| 看板打不开 | 端口被占用 | `Get-NetTCPConnection -LocalPort 8030` 查占用进程 |
| 扩展面板不出现 | 没加载扩展 / 没刷新页面 | `chrome://extensions` 重新加载，再 F5 |
| 面板显示 0 命中 | 关键词太窄 / 城市不对 | 放宽设置页的关键词 |
| 投递了但 BOSS 没消息 | 演练模式没关 | 检查设置页勾选状态 |
| git clone 卡住 / 超时 | 连不上 GitHub | 配代理（见第 1 步） |

## 只想临时跑一次？

不装 git 也行：GitHub 仓库页 → **Code** → **Download ZIP** → 解压。
但 ZIP **没有 git 历史**，也不能 `git pull` 更新，且同样需要手动做第 3、4、7 步。
